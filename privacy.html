隐私与访问统计说明

更新日期：2026-09-17

目前收集什么

本版本尚未启用站长侧访客统计，不设置统计 Cookie、不采集访客 IP、不记录点击或页面停留时间。浏览作品不需要注册。

网站托管平台 GitHub 会为安全目的记录访客 IP，该记录不等于作者拥有可查看的访客 IP 后台。详情请见 GitHub 隐私声明。视频和字体资源若由外部服务提供，也会产生对应的网络请求。

后续统计计划

如启用统计，将先更新本说明，明确服务商、用途、采集字段、保存期限及退出方式。默认优先聚合访问量、页面可见且活跃期间的停留时间、匿名点击率；原始 IP 不是识别访客身份的可靠依据。
