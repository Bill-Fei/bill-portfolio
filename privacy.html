隐私与访问统计说明

更新日期：2026-09-23

访问统计

启用统计后，网站会记录逻辑页面访问、页面停留秒数、设备类型（PC 或手机）、访问时间、来源站点的主域名，以及服务器收到的 IP。统计用于了解作品集是否被查看，不用于识别招聘者或建立跨站画像；不采集联系人文本、邮箱、电话或 URL 查询参数。

统计使用无 Cookie 的会话标识，仅在当前浏览器标签页会话中有效。停留时间按页面可见且近期有操作的时间累计，后台标签页和长时间无操作会暂停计时。历史数据不会补回，拒绝统计、浏览器拦截或网络失败会造成遗漏。

网站托管平台 GitHub 会为安全目的记录访客 IP，该记录不等于作者拥有可查看的访客 IP 后台。详情请见 GitHub 隐私声明。视频和字体资源若由外部服务提供，也会产生对应的网络请求。

保存与访问

数据保存在站长控制的统计后台，仅站长登录后可查看；管理密钥不会写入公开网站代码。原始 IP 属于敏感访问日志，自动保存 30 天后清空；页面访问、设备与停留等汇总记录可继续保留，用于观察作品集整体访问趋势。IP 不作为访客身份的可靠依据。
